## 🌟 الجديد في الإصدار 3.1 (Upgrade Overview)

يمثل الإصدار 3.1 ترقية هندسية كبرى وشاملة وفق وثيقة المواصفات الفنية المعتمدة (`MikroManager_Pro_Plan_v3`). تم بناء وتطوير المنظومة لتتجاوز مجرد إدارة الهوتسبوت التقليدية وتتحول إلى **منصة متكاملة لإدارة الشبكة الميدانية، الرصد المالي الدقيق، وتشخيص الأعطال**:

1. **بنية تحتية متطورة وجدولة الأوامر (`RouterOsCommandScheduler`):** منع تكرار الطلبات المتطابقة (De-duplication)، دعم التدفق المستمر للأوامر، والتراجع الأسي التلقائي عند بطء استجابة الراوتر.
2. **واجهات الشبكة والترافيك الحي (`/interfaces`):** قراءة تفصيلية لحالة المنافذ والبطاقات وسرعات النقل (Rx/Tx) برسم بياني حي مع أرشفة اللقطات اليومية.
3. **المشتركون الموحدون وأداة تشخيص الكروت (`/subscribers` و `/card-inquiry`):** توحيد مشتركي Hotspot و User Manager و PPPoE في واجهة واحدة، مع أداة تشخيص فورية تفحص انتهاء الوقت، استهلاك الرصيد، وأقفال MAC مع إمكانية فك القفل بلمسة واحدة.
4. **معرض القوالب التفاعلي وأنماط الحسابات الثلاثة (`/templates`):** محرر بصري لتصميم قوالب الكروت، ودعم توليد الكروت بنمط (كود موحد، كود مستخدم فقط، أو مستخدم وكلمة مرور منفصلين) مع دعم الإلغاء الفوري أثناء التوليد.
5. **طباعة حرارية متقدمة وأرشيف PDF (`/pdf-archive`):** معالجة النصوص العربية بنظام التحويل الصوري النقطي (Cairo PDF Rasterization) لحل مشاكل الطابعات الحرارية الميدانية نهائياً، مع سجل كامل لإعادة طباعة ومشاركة أي دفعة سابقة.
6. **محرك الأرقام الصادقة (Honest Numbers Reports Engine):** الفصل المحاسبي الصارم بين **قيمة المخزون الإجمالي**، و**المبيعات التقديرية الحقيقية** (المبنية حصرياً على رصد أول استخدام فعلي للكروت `usage_observations`)، و**المقبوضات المالية اليدوية الفعلية**، مع كشف الباقات غير المسعرة وتطبيق سياسة استبقاء البيانات.
7. **إدارة نقاط الوصول والأجهزة المجاورة (`/access-points`):** اكتشاف نقاط البث المتصلة بالراوتر عبر بروتوكولات MNDP و CDP، الكشف التلقائي عن الشركات المصنعة (MikroTik, Ubiquiti, TP-Link...)، وفحص حالة المنافذ وتخزين بيانات الاعتماد المشفرة.
8. **خريطة المشتركين وطوبولوجيا الشبكة (`/topology`):** ربط المشتركين بالأكسسات عبر سلم الأدلة الذكي (مؤكد، مرجح، غير محدد)، وعرض شجرة الشبكة التفاعلية في لوحة تدعم السحب والتكبير والتصغير وحفظ اللقطات.
9. **تنبيهات متقدمة وكشف DHCP الدخيل (`/telegram`):** كشف سيرفرات Rogue DHCP لحماية الشبكة من هجمات انتحال العناوين، جدولة ساعات الهدوء (Quiet Hours) لمنع الإزعاج ليلاً، ومولد سكربتات Netwatch مع تحذيرات مشددة لحماية التوكن.
10. **النسخ الاحتياطي الشامل للبيانات والراوتر (`/backup`):** تصدير واستيراد بيانات التطبيق بصيغة JSON المحمية بتجزئة SHA-256، مع أخذ نسخ احتياطية كاملة من الراوتر (`.backup`) وتصدير ملفات الإعدادات النصية (`.rsc`).
11. **ميزات اختيارية متقدمة (WireGuard & Hotspot Preview):** مساعد إعداد شبكات WireGuard VPN مع توليد رموز QR للهواتف، ومعاينة متجاوبة لصفحات الهوتسبوت بهياكل أجهزة متعددة (هاتف، تابلت، وشاشة كاملة).

## 🛡️ المتطلبات الصارمة والأمان (Hard Requirements)

- **بوابة الدخول الإلزامية وحارس المسارات (`RouteGuard`):** التطبيق يبدأ حصراً من مسار `/login` ولا يمكن الوصول لأي شاشة أو خدمة قبل المصادقة الفعلية.
- **اتصال حقيقي بالراوتر (Zero Mock in Release):** دعم كامل للاتصال الثنائي (Binary Socket) عبر منفذ `8728` أو مشفراً عبر `8729 (TLS)` مع دعم خيار قبول الشهادات الموقعة ذاتياً.
- **سياسة حماية الشبكة (RFC 1918):** تنبيه فوري وحوار تأكيد أمني عند محاولة الاتصال بعنوان راوتر عام بدون تفعيل تشفير TLS لمنع إرسال كلمات المرور عبر الإنترنت بشكل غير مشفر.
- **تأمين الأسرار والحد من محاولات التخمين:** تخزين كلمات المرور وتوكنات البوت والأكسسات في `FlutterSecureStorage` المشفر في نظام التشغيل حصراً. تجميد زر الدخول لمدة 30 ثانية تلقائياً بعد 5 محاولات خاطئة متتالية.
- **قاعدة بيانات Drift v2 الآمنة:** الترحيل التلقائي لقاعدة البيانات إلى `schemaVersion = 2` مع أخذ نسخة احتياطية محلية بصيغة `.bak` قبل الترقية لضمان عدم فقدان بيانات المستخدم السابقة.
- **واجهة عربية أصيلة 100%:** جميع النصوص والرسائل مستخرجة في ملفات التوطين الرسمية (`l10n/app_ar.arb`) ومصممة بخط Cairo بتوجيه كامل من اليمين لليسار (RTL) وفق مبادئ Material 3.

## ⚙️ إعداد راوتر MikroTik للربط بالتطبيق

لتتمكن من الاتصال بالراوتر من التطبيق، نفّذ الأوامر التالية عبر Terminal في WinBox أو SSH:

### 1. تفعيل خدمة API وضبط المنفذ:
```routeros
# تفعيل خدمة API العادية (المنفذ الافتراضي 8728)
/ip service enable api
/ip service set api port=8728

# أو تفعيل خدمة API-SSL المشفرة (المنفذ 8729)
/ip service enable api-ssl
/ip service set api-ssl port=8729
```

> [!TIP]
> **نصيحة أمنية:** يُوصى بحصر الوصول لمنفذ API على الشبكة المحلية أو عنوان هاتف الإدارة عبر تحديد خيار `address`:
> `/ip service set api address=192.168.88.0/24`

### 2. إنشاء مستخدم مخصص للتطبيق بصلاحيات محددة:
بدلاً من استخدام حساب `admin` الرئيسي، يمكنك إنشاء مستخدم مخصص:
```routeros
# لإنشاء مستخدم بكامل الصلاحيات (Admin):
/user add name=mikromanager group=full password="StrongPassword123"

# لإنشاء مستخدم مهندس شبكة (Engineer):
/user add name=engineer_user group=write password="EngineerPass123"

# لإنشاء مستخدم موزع كروت فقط (Reseller):
/user add name=reseller_user group=read password="ResellerPass123"
```

## 🧪 الاختبارات والجودة (Automated Testing)

المشروع مغطى باختبارات آلية شاملة (46 اختباراً آلياً بنسبة نجاح 100%) تضمن استقرار البروتوكول وسلامة البيانات:

* **اختبارات البروتوكول والشبكة (`routeros_protocol_test.dart` & `command_scheduler_test.dart`):** فحص دقة تشفير وفك أطوال الكلمات من 1 إلى 5 بايت، خوارزمية Legacy MD5، استجابات الأخطاء المصنفة، منع ازدواجية الطلبات، واستراتيجيات التراجع الأسي.
* **اختبارات قاعدة البيانات والهجرة (`database_test.dart`):** التحقق من عمليات التخزين والاسترجاع وهجرة المخطط v1 إلى v2 مع النسخ الاحتياطي التلقائي.
* **اختبارات حارس المسارات والواجهات (`widget_test.dart`):** إثبات أن التطبيق يبدأ في `/login` ويرفض انتقال أي مستخدم غير مسجل إلى أي مسار محمي.
* **اختبارات التحقق والأمان (`validators_test.dart`):** التحقق من دقة كشف نطاقات IPv4 الخاصة (RFC 1918) والمضيفات.
* **اختبارات المشتركين وتشخيص الكروت (`subscribers_diagnosis_test.dart`):** فحص دمج الهوتسبوت واليوزر منجر والـ PPPoE، وكشف انتهاء وقت وصلاحية الكروت وأقفال MAC.
* **اختبارات القوالب وتوليد الكروت (`templates_vouchers_test.dart`):** التحقق من أنماط الحسابات الثلاثة ومحرر القوالب وإلغاء التوليد.
* **اختبارات التقارير والأرقام الصادقة (`reports_engine_test.dart`):** فحص الفصل بين قيمة المخزون والمبيعات التقديرية بناء على أول ظهور، وتسجيل الدفعات اليدوية، وتنبيهات الباقات غير المسعرة.
* **اختبارات نقاط البث والشبكة (`access_points_test.dart` & `topology_test.dart`):** اختبار اكتشاف الأجهزة المجاورة (MNDP/CDP)، فحص المنافذ، وتصنيف سلم الأدلة لرسم الخريطة التفاعلية.
* **اختبارات التنبيهات المتقدمة وسيرفرات الـ DHCP (`alerts_rogue_dhcp_test.dart`):** التحقق من كشف الـ Rogue DHCP وساعات الهدوء وتوليد سكربتات Netwatch الآمنة.
* **اختبارات النسخ الاحتياطي والميزات الاختيارية (`backup_test.dart` & `optional_features_test.dart`):** فحص سلامة تصدير واستيراد البيانات مع مطابقة SHA-256، وإعدادات WireGuard، ومعاينة الهوتسبوت.

لتشغيل الفحص والتحليل والاختبارات:
```bash
flutter analyze
flutter test
```
