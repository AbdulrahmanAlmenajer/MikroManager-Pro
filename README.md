## 💡 فكرة المشروع والتحسينات في الإصدار 2.0

كثير من مديري وموزعي شبكات MikroTik في الميدان يحتاجون إلى أداة محمولة فائقة الأمان وسريعة لإدارة شبكات الهوتسبوت وسيرفرات User Manager، مع توليد وطباعة كروت المشتركين فورياً عبر الطابعات الحرارية المحمولة (58mm/80mm) أو تصديرها كصفحات A4 جاهزة للقص والتوزيع مع رمز QR للتسجيل السريع.

في **الإصدار 2.0 المحسّن** تم بناء وتأمين التطبيق وفق أحدث معايير الأمان والتصميم:
1. **بوابة تسجيل الدخول الإلزامية وحماية المسارات (Route Guard):** التطبيق يبدأ حصراً من مسار `/login` ولا يُسمح بالوصول إلى أي شاشة أو خدمة قبل نجاح الاتصال الفعلي بالراوتر ومصادقة المستخدم.
2. **اتصال حقيقي متكامل بالراوتر (Real RouterOS Authentication):**
   - اتصال مباشر عبر بروتوكول Binary Socket على المنفذ `8728` أو مشفراً بـ TLS/SSL على `8729`، مع دعم خيار قبول الشهادات ذاتية التوقيع (Self-Signed Certificates).
   - دعم المصادقة الحديثة لراوترات MikroTik (v6.43+ و v7) والمصادقة القديمة (Legacy Challenge/MD5).
   - التحقق الفوري من صحة الاتصال عبر `/system/resource/print`، وكشف إصدار RouterOS واسم البورد والمعالج.
3. **استنتاج الصلاحيات والأدوار تلقائياً من الراوتر (Role-Based Access):**
   - قراءة صلاحيات المستخدم من مجموعته في الراوتر عبر `/user/print` و `/user/group/print`:
     - **مدير النظام (Admin):** وصول كامل لجميع الشاشات والإعدادات وبوت تيليجرام.
     - **مهندس شبكة (Engineer):** وصول للوحة التحكم، الهوتسبوت، اليوزر منجر، وإعدادات الشبكة.
     - **موزع كروت (Reseller):** وصول محدد لتوليد الكروت، طباعتها، وعرض المبيعات فقط.
4. **حماية أمنية من هجمات التخمين (Rate Limiter):** عند حدوث 5 محاولات دخول خاطئة متتالية يتم تجميد زر تسجيل الدخول لمدة 30 ثانية.
5. **تخزين آمن تماماً (Zero Plaintext Secrets):** كلمات مرور الراوتر والتوكن لا تُحفظ في قواعد البيانات العادية إطلاقاً، بل تُشفّر حصرياً عبر `FlutterSecureStorage` في KeyStore/Keychain النظام.
6. **لغة عربية كاملة بنظام التوطين الرسمي (Flutter ARB l10n):** جميع النصوص مستخرجة في ملفات ترجمة رسمية بنظام RTL والخط العربي Cairo.

## ✨ المميزات الرئيسية للمشروع

### 1. شاشة تسجيل الدخول وبوابة الأمان (/login)
- تحقق صارم من صيغة عنوان IP أو اسم المضيف، ورقم المنفذ (1–65535).
- أزرار اختيار سريع للمنافذ: `8728 (عادي)` و `8729 (SSL)`.
- قائمة منسدلة/شرائح للاتصالات السابقة المحفوظة لتعبئة البيانات بلمسة واحدة.
- رسائل خطأ دقيقة ومصنفة (انقطاع الاتصال، المنفذ مغلق، خطأ في اسم المستخدم أو كلمة المرور، فشل شهادة TLS، أو نقص صلاحيات API).

### 2. محرك RouterOS Socket المتطور
- ترميز وفك أطوال الكلمات من 1 إلى 5 بايت وفق مواصفة MikroTik الرسمية.
- التعامل مع جميع جمل الرد (`!re`، `!done`، `!trap`، `!fatal`).
- تمييز الأوامر عبر وسوم (`.tag`) لدعم إرسال عدة استعلامات في وقت واحد.
- دعم الاستماع المستمر وتدفق البيانات اللحظي (`streamSentence` لـ `/interface/monitor-traffic`) مع إمكانية الإلغاء الفوري (`/cancel`).
- إعادة محاولة الاتصال التلقائي حتى 3 مرات عند انقطاع الشبكة المؤقت.

### 3. لوحة المراقبة الحية (Dashboard)
- استهلاك المعالج (CPU %)، الذاكرة المتاحة والإجمالية (RAM)، ومدة تشغيل الراوتر (Uptime).
- رسم بياني حي لمعدل نقل البيانات (Rx / Tx بالـ Mbps) عبر مكتبة `fl_chart`، بتحديث دوري كل 3 ثوانٍ ويُلغى تلقائياً عند مغادرة الشاشة لمنع استنزاف الموارد.

### 4. إدارة الهوتسبوت (Hotspot) مع 4 تبويبات شاملة
- **المستخدمون (Users):** استعراض المشتركين، الإضافة، وتعيين البروفايل ومهلة الجلسة.
- **المتصلون النشطون (Active Sessions):** عرض الجلسات النشطة، عناوين IP و MAC، مع زر فصل المشترك فورياً (**Kick**) بعد تأكيد المستخدم.
- **ملفات السرعة (Profiles):** عرض وتخصيص الباقات وسقف السرعات.
- **ربط العناوين (IP Bindings):** إدارة وتجاوز العناوين الثابتة (Bypassed / Regular / Blocked).
- توثيق كل عملية حذف أو Kick تلقائياً في سجل الرقابة والتدقيق (`audit_logs`).

### 5. مدير المستخدمين (User Manager)
- دعم كامل لإصدارات UserManager القديمة (v6 مسار `/tool/user-manager`) والحديثة (v7 مسار `/user-manager`).
- عرض المستخدمين، الباقات، والجلسات النشطة.

### 6. محرك توليد وطباعة الكروت (Vouchers & Printing)
- توليد كروت فريدة باستخدام المولد المشفر الآمن `Random.secure()`.
- تفادي الأحرف الملتبسة (مثل `0` و `O`، و `1` و `I` و `l`).
- رفع الكروت إلى الراوتر على دفعات مجدولة (50 كرت في كل دفعة) مع مؤشر تقدم وإمكانية الإلغاء.
- **طباعة A4 PDF:** تخطيط شبكي احترافي (3 أعمدة، 12 كرت بالصفحة) مع رمز QR Code لتسجيل الدخول السريع.
- **طباعة حرارية ميدانية (ESC/POS 58mm/80mm):** طباعة الإيصالات الحرارية عبر البلوتوث مع معالجة النصوص العربية بصيغة صورية (Raster Image) لضمان عدم تشوه أو انعكاس الحروف على طابعات الإيصالات.

### 7. التقارير المالية والإحصائيات (Reports)
- رسوم بيانية للمبيعات اليومية والشهرية.
- تصدير التقارير بصيغة **PDF** رسمية قابلة للمشاركة والطباعة.
- تصدير الجداول بصيغة **CSV** لتسهيل التحليل على برامج الجداول الإلكترونية كـ Excel.

### 8. بوت تيليجرام للتنبيهات الفورية (Telegram Bot)
- تكامل مباشر مع Telegram Bot API عبر Dio لإرسال التنبيهات:
  - تنبيه عند انقطاع أو عودة الراوتر للعمل.
  - تنبيه عند ارتفاع استهلاك المعالج عن 90%.
  - تنبيه عند اقتراب نفاد الكروت الجاهزة.
  - إرسال رسالة اختبارية للتحقق من صحة رمز البوت (Token) ومعرّف المحادثة (Chat ID).

## ⚙️ إعداد راوتر MikroTik للربط بالتطبيق

لتتمكن من الاتصال بالراوتر من التطبيق، نفّذ الأوامر التالية عبر Terminal في WinBox أو SSH:

### 1. تفعيل خدمة API وضبط المنفذ:
```routeros
# تفعيل خدمة API العادية (المنفذ الافتراضي 8728)
/ip service enable api
/ip service set api port=8728

# أو تفعيل خدمة API-SSL المشفرة (المنفذ 8729)
/ip service enable api-ssl
/ip service set api-ssl port=8729
```

> [!TIP]
> **نصيحة أمنية:** يُوصى بحصر الوصول لمنفذ API على الشبكة المحلية أو عنوان هاتف الإدارة عبر تحديد خيار `address`:
> `/ip service set api address=192.168.88.0/24`

### 2. إنشاء مستخدم مخصص للتطبيق بصلاحيات محددة:
بدلاً من استخدام حساب `admin` الرئيسي، يمكنك إنشاء مستخدم مخصص:
```routeros
# لإنشاء مستخدم بكامل الصلاحيات (Admin):
/user add name=mikromanager group=full password="StrongPassword123"

# لإنشاء مستخدم مهندس شبكة (Engineer):
/user add name=engineer_user group=write password="EngineerPass123"

# لإنشاء مستخدم موزع كروت فقط (Reseller):
/user add name=reseller_user group=read password="ResellerPass123"
```

المشروع مغطى باختبارات آلية شاملة تضمن استقرار البروتوكول وتأمين المسارات:
* **اختبارات ترميز البروتوكول (`routeros_protocol_test.dart`):** فحص دقة تشفير وفك أطوال الكلمات من 1 إلى 5 بايت، خوارزمية Legacy MD5، واستجابات الأخطاء المصنفة.

* **اختبارات توليد الكروت (`voucher_generator_test.dart`):** التأكد من فرادة الأكواد وعدم تكرارها واستبعاد الرموز الملتبسة.
* **اختبارات حارس المسارات والواجهات (`widget_test.dart`):** إثبات أن التطبيق يبدأ في `/login` ويرفض انتقال أي مستخدم غير مسجل إلى `/dashboard` أو غيرها من المسارات المحمية.
