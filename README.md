## 💡 فكرة المشروع والدافع الهندسي

كثير من مديري الشبكات ومهندسي الاتصالات في الميدان يواجهون معاناة حقيقية في إدارة شبكات MikroTik (سواء شبكات الهوتسبوت أو سيرفرات User Manager). تطبيق WinBox رائع ومتقدم ولكنه صُمم للشاشات الكبيرة وأجهزة الكمبيوتر، واستخدامه على الموبايل عبر تطبيقات الطرف الثالث غير مريح إطلاقاً، ناهيك عن عدم وجود نظام مدمج وسهل لتوليد كروت المشتركين وطباعتها مباشرة عبر طابعات البلوتوث الحرارية المحمولة (58mm/80mm) أو تصديرها كصفحات A4 جاهزة للقص والتوزيع مع رمز QR للتسجيل السريع.

من هنا انطلقت فكرة **MikroManager Pro**:
تطبيق هجين، عربي بالكامل (RTL)، مبني بمعمارية Clean Architecture مع Riverpod، يعمل بنظام **Local-First** لحفظ الدفعات والسجلات محلياً حتى في حال انقطاع الاتصال بالراوتر، ويقدم تجربة مستخدم عصرية وسلسة تتيح لمالك الشبكة أو الوكلاء إدارة كل شيء من راحة هواتفهم.

## ✨ المميزات الرئيسية للمشروع

### 1. محرك الاتصال المزدوج براوترات MikroTik (RouterOS Engine)
- **Binary Socket Client (Port 8728 / 8729 SSL):** اتصال Socket مباشر وسريع جداً عبر بروتوكول MikroTik الرسمي مع دعم تشفير وفك طول الكلمات (Word Length Encoding) ودعم المصادقة الحديثة (Post-6.43) والتحدي التشفيري القديم (Legacy MD5 Challenge).
- **REST API Client (Port 80 / 443):** دعم كامل للراوترات الحديثة العاملة بنظام RouterOS v7+.
- **RouterOsAdapter:** طبقة وسيطة موحدة تخفي تفاصيل البروتوكول وإصدار النظام عن واجهات التطبيق.
- **فحص الاتصال اللحظي:** فحص استجابة الراوتر والتأكد من فتح بورتات API مع تنبيهات فورية.

### 2. إدارة متكاملة لخدمتي Hotspot و User Manager
- **المتصلون النشطون (Active Sessions):** عرض المتصلين حالياً وعناوين IP و MAC ومدة الاتصال وحجم الاستهلاك (رفع وتنزيل)، مع زر قطع الاتصال الفوري (**Kick**) بلون الخطر التنبيهي.
- **إدارة المستخدمين والبروفايلات:** إضافة وتعديل وحذف الكروت، تحديد السرعات (Rate Limits)، تحديد مهلة الجلسة وسقف البيانات بالبايت.
- **سجل التدقيق (Audit Logs):** توثيق كل عملية توليد، حذف، أو قطع اتصال محلياً في قاعدة البيانات لأغراض الجرد والمحاسبة.

### 3. محرك توليد وطباعة الكروت (Voucher Generator & Printing)
- **محرك كروت فريدة:** توليد دفعات كروت عشوائية غير قابلة للتكرار، مع التحكم في البادئة (Prefix)، طول الكود (4، 6، 8، 10 خانات)، ونوع المحارف (أرقام فقط، أرقام وحروف، حروف كبيرة).
- **خيارات الدخول:** إمكانية جعل اسم المستخدم مطابقاً لكلمة المرور (كود موحد) لتسهيل دخول المشترك.
- **مزامنة فورية وتخزين محلي:** رفع الكروت مباشرة إلى الراوتر مع حفظ نسخة كاملة في قاعدة بيانات Drift لإعادة الطباعة والجرد دون الحاجة للاتصال بالراوتر.
- **طباعة A4 PDF مع QR Code:** تخطيط شبكي احترافي (3 كروت في الصف، 12 كرت في الصفحة) مع رمز QR لتسجيل الدخول السريع عبر كاميرا هاتف المشترك.
- **طباعة حرارية ميدانية (ESC/POS):** دعم طباعة الكروت الفردية فورياً عبر طابعات البلوتوث المحمولة بمقاسي `58mm` و `80mm`.

### 4. لوحة المراقبة الحية والتقارير المالية (Dashboard & Analytics)
- **مؤشرات النظام الحية:** متابعة استهلاك المعالج (CPU %)، الذاكرة المتاحة (RAM)، ومدة تشغيل الراوتر (Uptime).
- **رسم بياني حي للترافيك:** استخدام مكتبة `fl_chart` لرسم استهلاك التنزيل (Rx) والرفع (Tx) بالـ Mbps في الوقت الحقيقي مع إمكانية التبديل بين كروت الشبكة (Interfaces).
- **تقارير المبيعات والأرباح:** رسوم بيانية بالأعمدة للمبيعات حسب البروفايل وحساب صافي الأرباح وإمكانية تصدير تقارير مالية كاملة بصيغة PDF.
- **تكامل بوت تيليجرام (Telegram Bot):** إرسال تنبيهات المبيعات اليومية وتنبيهات أعطال الراوتر تلقائياً عبر البوت.

## 🏛️ المعمارية الهندسية وهيكلية المشروع

تم تنظيم المشروع باتباع مبدأ **Feature-First Clean Architecture**:

```
lib/
├── main.dart                               # نقطة الدخول وتهيئة الثيم وRTL
├── core/                                   # المكونات المشتركة
│   ├── constants/                          # الألوان، الثيم، وبورتات API
│   │   ├── api_constants.dart
│   │   ├── app_colors.dart
│   │   └── app_theme.dart
│   ├── database/                           # قاعدة البيانات المحلية (Drift)
│   │   ├── app_database.dart
│   │   ├── database_provider.dart
│   │   └── tables/                         # جداول الراوترات، الكروت، التقارير، والسجلات
│   ├── network/                            # محرك الاتصال بـ RouterOS
│   │   ├── routeros_adapter.dart           # الواجهة الموحدة
│   │   ├── routeros_socket_client.dart     # عميل Binary Socket (ports 8728/8729)
│   │   └── routeros_rest_client.dart       # عميل REST API (ports 80/443)
│   ├── router/                             # مسارات الملاحة GoRouter
│   │   └── app_router.dart
│   ├── security/                           # تشفير كلمات المرور في مخزن النظام
│   │   └── secure_storage_service.dart
│   └── utils/                              # المساعدات التقنية والطباعة
│       ├── audit_logger.dart               # مسجل التدقيق والعمليات
│       ├── esc_pos_helper.dart             # أوامر الطابعات الحرارية ESC/POS
│       └── pdf_generator_helper.dart       # منشئ مستندات PDF وشبكات الكروت
└── features/                               # الميزات الأساسية للتطبيق
    ├── dashboard/                          # لوحة المراقبة والرسم البياني
    ├── hotspot/                            # إدارة مستخدمي ومتصلي الهوتسبوت
    ├── reports/                            # التقارير المالية ومخططات المبيعات
    ├── routers/                            # إدارة وفحص الاتصال بالراوترات
    ├── settings/                           # إعدادات الطابعات وتيليجرام
    ├── userman/                            # إدارة User Manager v6 & v7
    └── vouchers/                           # محرك توليد ومعاينة الكروت
```

## 🛡️ القرارات الأمنية المعتمدة في النظام

1. **عدم تخزين كلمات المرور كنصوص واضحة:** لا يتم تخزين كلمات مرور أجهزة MikroTik أو مفاتيح Telegram Bot داخل قاعدة بيانات SQLite المحلية، بل تُحفظ دائماً مشفرة داخل **Flutter Secure Storage** (باستخدام `EncryptedSharedPreferences` في أندرويد و `Keychain` في iOS).
2. **بروتوكول Local-First:** إمكانية تشغيل التطبيق وجرد المبيعات وإعادة طباعة الكروت القديمة بالكامل دون الحاجة لوجود إنترنت أو اتصال حي بالراوتر.
3. **دعم الاتصال المشفر:** دعم بورت `8729` (API-SSL) وبورت `443` (HTTPS) لتأمين نقل البيانات عبر الشبكة.

## 🚀 طريقة التثبيت والتشغيل والتطوير

### المتطلبات الأساسية:
- Flutter SDK (الإصدار 3.24+ أو 3.50)
- Dart SDK (الإصدار 3.5+)
- جهاز أندرويد، محاكي، أو بيئة نظام ويندوز

### خطوات التشغيل:
```bash

git clone git@github.com:AbdulrahmanAlmenajer/MikroManager-Pro.git
cd MikroManager-Pro

# 3. تشغيل الاختبارات للتأكد من سلامة الكود

flutter run
```
